# The Binding of Isaac: Four Souls — Русская локализация

Неофициальный перевод карточной игры **The Binding of Isaac: Four Souls** на русский язык.

## О проекте

Цель проекта — перевести карты Four Souls на русский язык, сохранив оригинальные иллюстрации и визуальный стиль.

## Содержимое

- Локализованные изображения карт
- Шрифты с поддержкой кириллицы
- Материалы для перевода и локализации

## Статус проекта

**В разработке.** Карты переводятся и добавляются по мере готовности.
